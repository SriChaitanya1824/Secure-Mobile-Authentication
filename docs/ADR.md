# Architectural Decision Records (ADRs)

- **ADR-001**: Kotlin + Jetpack Compose for modern, declarative, state-driven Android UI.
- **ADR-002**: MVVM + Clean Architecture for separation of concerns and testability.
- **ADR-003**: Room Database for offline-first local persistence and reactive Flow observation.
- **ADR-004**: Retrofit + OkHttp with Kotlin Serialization for type-safe REST communication.
- **ADR-005**: Android Keystore AES-256-GCM for hardware-backed local credential encryption.
- **ADR-006**: BiometricPrompt for secure biometric wallet unlocking.
- **ADR-007**: Ed25519 Digital Signatures for high performance and compact verifiable credentials.
- **ADR-008**: Dynamic Signed QR Codes with nonce replay protection for presentation sharing.
- **ADR-009**: Offline-First Repository Architecture with timestamp-based delta synchronization.
- **ADR-010**: PostgreSQL for ACID-compliant relational data storage.
- **ADR-011**: Flyway for reliable, versioned database schema migrations.
- **ADR-012**: Status List & Idempotent Revocation API for tamper-evident lifecycle management.
